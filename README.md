# BlockBuild

Minecraft Bedrock Edition için telefon üzerinde dünya ve yapı yönetimi uygulaması.

## Phase 1

- Android/Jetpack Compose temel arayüz
- `.mcworld`, `.mcpack`, `.mcaddon` ve `.zip` dosyası seçme
- İçe aktarılan dosyaları uygulama içinde listeleme
- Dosya boyutunu gösterme
- İçe aktarılan dosyayı listeden kaldırma
- Yapı Kütüphanesi için temel ekran
- GitHub Actions ile debug APK oluşturma

## Sonraki fazlar

- Phase 2: `.mcstructure` okuma/yazma ve yapı kütüphanesi
- Phase 3: `.mcworld` içinden yapı/alan çıkarma
- Phase 4: yapıyı başka `.mcworld` içine yerleştirme
- Phase 5: koordinat, döndürme, aynalama, önizleme ve gelişmiş araçlar
